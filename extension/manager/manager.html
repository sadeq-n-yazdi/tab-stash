        Settings

        A preview can show private data of the page. If you change this setting, the extension moves the previews that you have. The server options work only when you are logged in to a sync server.

        Sync server

        Keep the same stash on all your computers with your own Tab Stash server.

        The extension keeps a login token, not your password. The first sync sends all your groups and saved tabs to the server.
